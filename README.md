# 👗 Bella Modas

Site institucional da **Bella Modas**, criado para apresentar a loja, exibir as peças disponíveis e facilitar o contato com clientes pelo WhatsApp e Instagram.

🔗 **Acesse o site:** [ozorio01.github.io/Bella-Modas](https://ozorio01.github.io/Bella-Modas/)

---

## 📖 Sobre o projeto

A Bella Modas atendia seus clientes apenas pelo WhatsApp e Instagram. Este site foi criado para dar mais um canal de visibilidade à loja, mostrando novidades, produtos disponíveis e informações de contato de forma organizada.

## ✨ Funcionalidades

- Menu de navegação responsivo, com versão em hambúrguer para celular
- Seção de novidades e vitrine de produtos
- Seção "Sobre" contando a história da loja
- Botão de contato direto via WhatsApp (fixo na tela e na seção de contato)
- Link para o Instagram da loja
- Layout responsivo (desktop, tablet e celular)

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
